# AI Career Assistant

A command-line AI Career Assistant built with Python and Google's Gemini API.

---

## Features

- AI Career Coach
- Gemini API
- Conversation History
- Timestamp
- Question Counter
- Help Commands
- Clear History
- Save History to File
- Exception Handling

---

## Installation

```bash
git clone <repository>

cd ai-career-assistant

python -m venv venv

pip install -r requirements.txt

python main.py
